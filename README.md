# 🏢 부동산 블로그 썸네일 자동 생성기 (1080x1080)

첨부된 시안의 세련된 디자인 톤앤매너(사선 분할 배경, 주황색 강조 포인트, 볼드 타이포그래피, 하단 고정 띠지)를 계승하면서, 네이버 블로그 및 스마트플레이스, 인스타그램에 가장 최적화된 **1080 x 1080 (1:1 정사각형)** 규격으로 자동 렌더링하는 파이썬 기반 웹 애플리케이션입니다.

---

## 📱 스마트폰 외부 임장 접속 (비밀번호: 4989)

사무실이나 집 밖으로 임장을 나갔을 때, 스마트폰(LTE/5G)으로 접속하여 현장에서 찍은 거실/방 사진을 즉시 1080x1080 고화질 썸네일로 제작할 수 있습니다.

### 사용 방법:
1. 컴퓨터에서 **`모바일_임장용_실행.bat`** 파일을 더블클릭합니다.
2. 화면에 나타나는 **스마트폰 접속 링크**를 클릭하거나, 자동으로 열리는 **QR코드**를 스마트폰 기본 카메라로 스캔합니다.
   *(접속 링크가 컴퓨터 클립보드에 자동 복사되므로, 카카오톡 '나와의 채팅'에 붙여넣어 폰으로 누르셔도 됩니다!)*
3. 스마트폰 화면에 나타나는 로그인 창에 비밀번호 **`4989`** (사고팔고)를 입력합니다.
4. 현장에서 폰으로 촬영한 사진을 올리고 매물 정보를 입력한 뒤 **`1080x1080 썸네일 저장`**을 터치하면 스마트폰 갤러리에 즉시 저장됩니다!

## 🌟 주요 기능

1. **와이드 사진 노출 극대화**:
   - **와이드 사선 분할형**: 사진 면적 68%~75% 확장 (거실/실내 전경 추천)
   - **상하 파노라마 와이드형**: 가로 100% 전경 노출 (소파부터 창문 뷰까지 100% 노출)
   - **표준 사선 분할형**: 기본 5:5 세로형 외관 사진용

2. **사진 가로 비중 & 미세 조정**:
   - 사진 너비 조절 슬라이더 (50% ~ 76%)
   - 사진 좌우/상하 이동 및 확대/축소 지원

3. **고정 요소 보존**:
   - 하단 검은색 띠지에 참좋은공인중개사사무소 공식 로고 및 `010-9667-4201` 고정 출력

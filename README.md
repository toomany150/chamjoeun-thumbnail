# 🏢 부동산 블로그 썸네일 & 네이버광고 대상중개물표시 올인원 마스터

공인중개사 실무에 최적화된 **1080x1080 블로그 썸네일 자동 생성기**와 **네이버 부동산 광고 입력 순서 16개 점검표 & 법정 대상중개물 표시 서식 생성기**가 하나로 통합된 올인원 자동화 프로그램입니다.

---

## 📱 스마트폰 외부 임장 & PC 동시 지원 (접속 비밀번호: 4989)

사무실(PC)뿐만 아니라, 외부 임장 현장에서도 스마트폰(LTE/5G)으로 접속하여 찍은 사진으로 즉시 썸네일을 만들고 네이버 광고 및 블로그 확인설명 서식을 즉시 생성할 수 있습니다.

### 사용 방법:
1. 컴퓨터에서 **`모바일_임장용_실행.bat`** (또는 내 PC 전용 `실행하기.bat`)을 더블클릭합니다.
2. 화면에 나타나는 QR코드를 스마트폰으로 스캔하거나, 링크를 엽니다.
3. 로그인 창에 비밀번호 **`4989`** (사고팔고)를 입력합니다.
4. **1단계 썸네일 생성** ➜ **2단계 네이버광고 점검표 확인** 순서로 원스톱 처리!

## 🌟 주요 기능 구성 (상단 탭 전환)

### [ 탭 1 ] 🎨 1단계: 블로그 썸네일 생성기 (1080x1080)
- **와이드 사진 노출 극대화**:
  - **와이드 사선 분할형**: 사진 면적 68%~75% 확장 (거실/실내 전경 추천)
  - **상하 파노라마 와이드형**: 가로 100% 전경 노출 (소파부터 창문 뷰까지 100% 노출)
  - **표준 사선 분할형**: 기본 5:5 세로형 외관 사진용
- **사진 가로 비중 & 미세 조정**: 사진 줌(0.6~2.0배), 좌우/상하 이동 슬라이더
- **고정 요소 보존**: 하단 검은색 띠지에 참좋은공인중개사사무소 공식 로고 및 `010-9667-4201` 고정 출력

---

### [ 탭 2 ] 📝 2단계: 네이버 광고 점검표 & 대상중개물 표시 (신소장님 지정 순서 16개)
네이버 부동산 매물 등록창의 순서와 1:1로 정확하게 일치하도록 구성되어, 화면을 띄워두고 위에서 아래로 보면서 빠르고 정확하게 광고를 등록할 수 있습니다.

| 번호 | 체크 항목 | 비고 / 신소장님 확인 사항 |
| :---: | :--- | :--- |
| **01** | **소재지** | 동·리 및 지번 표기 필수 (아파트 동·호수는 생략 가능) |
| **02** | **공급 / 전용면적** | 평수 병기 시 ㎡ 반드시 함께 표기 (전용률% 및 평수 자동 계산) |
| **03** | **해당층 / 총층** | 예: 25 / 36층 (저/중/고층 대체 표기 지원) |
| **04** | **방수 / 욕실수** | 건축물대장 기준 방 및 욕실 개수 |
| **05** | **관리비** | 월 10만 원 이상 시 세부내역(공용/전기/수도 등) 분리 기재 필수 |
| **06** | **거래 형태** | 매매, 전세, 월세 중 1개 명시 |
| **07** | **가격 (기보증금/월세)** | 거래 형태에 따른 정확한 가격 및 기존 임대차 승계 명시 |
| **08** | **방향** | 주실(거실) 창문 기준 명확히 기재 |
| **09** | **현관구조** | 계단식, 복도식, 복합식 중 선택 |
| **10** | **난방 (방식/연료)** | 개별난방/도시가스, 지역난방/열병합 등 |
| **11** | **입주가능일** | 즉시입주 협의가능 또는 날짜 명시 |
| **12** | **총주차대수** | 단지 총 주차대수 및 세대당 대수 (예: 1,685대 / 세대당 1.07대) |
| **13** | **해당면적 세대수** | 해당 평형 세대수 및 총 세대수 병기 |
| **14** | **건축물 용도** | 건축물대장 기준 부합 (공동주택, 업무시설 등) |
| **15** | **사용승인일** | 건축물대장 상 사용승인일 필수 기재 |
| **16** | **중개사무소 정보** | 참좋은공인중개사사무소 (대표 신제환, 010-9667-4201, 등록번호, 주소) 고정 |

#### 🚀 3가지 원클릭 산출물:
1. **📋 네이버광고 점검표 (대조용)**: 네이버 광고창 보며 그대로 입력하는 1:1 체크리스트
2. **📝 네이버 블로그 스마트에디터 표 서식**: 본문에 복사-붙여넣기 가능한 깔끔한 HTML 표 및 텍스트
3. **🖼️ 고화질 중개대상물 표시 카드 (PNG)**: 모바일 갤러리 또는 블로그 하단에 넣는 1080px 카드 이미지
